### Exercícios e Projetos em Python
***1. Jogo de adivinhação de números no Python***
- O sistema gera um número aleatório de 0 a 100. O jogador escolhe a dificuldade, significando o número de tentativas que ele possui.
- O jogador diz um número e o computador informa se o número secreto é maior ou menor. Acertando, o programa informa o acerto e quantas tentativas necessárias. Errando, o sistema informa qual o número.
- O jogador pode jogar quantas vezes quiser, e ao finalizar recebe um retorno de quantas sessões foram jogadas, quantas ganhou e quantas perdeu.
